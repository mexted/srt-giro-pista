# Gioco giro pista solo

Gioco per telefono della presentazione della stagione 2027 di SOLO Racing Team.
Si guida una Aprilia RS 660 sul circuito della presentazione: telefono in orizzontale, si inclina per piegare,
pollice destro gas, pollice sinistro freno. Per giocare serve registrarsi; i tempi finiscono nella classifica dell'evento.
